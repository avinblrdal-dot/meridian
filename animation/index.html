Dark variant, for the navy sections of the site

The Meridian site alternates cream and navy sections. Add data-theme="dark" and the embed sits on navy without a seam. The phone mockups stay light in both, because a phone screen is a phone screen.

How to embed it

Two lines. Drop them anywhere in the page — Squarespace, Wix, WordPress, a hand-written HTML file, a page builder's "custom code" block. 

<div data-meridian-flow data-business="Ivy Lane Studio"></div>
<script src="https://YOUR-DOMAIN/js/meridian-flow.js"></script>

Options, all optional, all set as data attributes:

data-business="Ivy Lane Studio"   name shown in the animation
data-theme="dark"                for navy sections (default is light)
data-speed="1.25"                playback multiplier (1 = normal)
data-autoplay="false"            wait for the user to scroll to it
data-pause-on-hover="false"      keep playing when hovered
data-loop="false"                play once, stop on the final frame
