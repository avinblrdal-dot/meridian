Adding the assistant to your website

One line of code, pasted once. It takes about two minutes, and you'll never need to touch it again — we update the answers from our end.

1 Copy this line

This is the whole thing. Don't retype it — use the copy button, because one wrong character stops it working.


  


  

    Nothing here is secret. This line is safe to email, paste
    into a support ticket, or hand to whoever looks after the website. It
    contains no password and no key.
  


  
2 Paste it into your website

  
Find your platform below. You're looking for the box called
     “custom code”, “code injection”, or
     “footer scripts” — every platform has one, they all
     just call it something different.


  

    Squarespace
    

      
    
        
  1. Log in and open Settings.
    2. 
        
  2. Go to Advanced → Code Injection.
    3. 
        
  3. Paste the line into the Footer box (not Header).
    4. 
        
  4. Save, then open your site in a new tab to check.
    5. 
      

      
Code Injection needs a
         Business plan or higher. If you don't see it, that's why.

    

  


  

    Wix
    

      
    
        
  1. In your dashboard, go to Settings → Custom Code.
    2. 
        
  2. Click + Add Custom Code.
    3. 
        
  3. Paste the line into the code box.
    4. 
        
  4. Under “Add Code to Pages” choose All pages.
    5. 
        
  5. Under “Place Code in” choose Body - end.
    6. 
        
  6. Apply, then publish your site.
    7. 
      

    

  


  

    WordPress
    

      
    
        
  1. Install the free plugin WPCode (or
            Insert Headers and Footers).
    2. 
        
  2. Open Code Snippets → Header & Footer.
    3. 
        
  3. Paste the line into the Footer box.
    4. 
        
  4. Save Changes.
    5. 
      

      
If your theme has its own
         “custom scripts” setting, that works too — no plugin
         needed.

    

  


  

    Shopify
    

      
    
        
  1. Go to Online Store → Themes.
    2. 
        
  2. On your live theme, click … → Edit code.
    3. 
        
  3. Open theme.liquid under Layout.
    4. 
        
  4. Paste the line just above the closing
            </body> tag near the bottom.
    5. 
        
  5. Save.
    6. 
      

    

  


  

    GoDaddy, Weebly, Square Online
    

      
    
        
  1. Look in Settings for Custom Code, Embed Code, or
            Advanced.
    2. 
        
  2. Choose the option that adds code to every page, at the
            end of the body or in the footer.
    3. 
        
  3. Paste and save, then publish.
    4. 
      

      
Can't find it? Send us a
         screenshot of your settings menu and we'll point at the right one.

    

  


  

    A hand-built site (raw HTML)
    

      
    
        
  1. Open your page template — whichever file every page shares.
    2. 
        
  2. Paste the line immediately before </body>.
    3. 
        
  3. Upload and you're done.
    4. 
      

    

  


  
3 Check it worked

  
Open your website in a new browser tab and look at the bottom-right corner.

  
    
    
  • A round gold chat button is there.
    • 
    
  • Clicking it opens the chat, with your business name at the top.
    • 
    
  • Asking about your hours gives your real hours back.
    • 
  


  

    Don't see it? Nine times out of ten the page is cached.
    Do a hard refresh — Ctrl+Shift+R on Windows,
    Cmd+Shift+R on a Mac — or open your site in a private window.
    If it's still missing, check the code went in the footer or
    end of body box, and that you published the site afterwards.
    Then tell us and we'll sort it.
